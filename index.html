¿Qué es el FR? Es el factor territorial que ajusta el honorario según el colegio o zona de referencia. No existe un único valor por región: dentro de algunas regiones hay colegios con FR distintos. Por ello el selector muestra el colegio/zona y aplica su valor específico. Para esta versión se establece Sinaloa como referencia inicial (Región V, FR 0.95).
