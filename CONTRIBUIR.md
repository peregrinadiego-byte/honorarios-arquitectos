# 🤝 Contribuir

## ¿Quieres mejorar esta herramienta?

Las contribuciones son bienvenidas. Algunas áreas donde se necesita ayuda:

### Propuestas de mejora
- [ ] Agregar más géneros constructivos
- [ ] Exportación a PDF nativo
- [ ] Exportación a Excel
- [ ] Base de datos para histórico
- [ ] Dashboard de propuestas
- [ ] Integración con CRM
- [ ] QR de validación

### Bugs o problemas
Si encuentras un bug:
1. Describe el problema claramente
2. Incluye pasos para reproducirlo
3. Especifica sistema operativo y navegador

### Nuevas características
Antes de desarrollar:
1. Abre una "issue" describiendo la idea
2. Espera feedback
3. Desarrolla en rama nueva
4. Haz pull request

## Proceso de contribución

```bash
# 1. Fork del repositorio
# 2. Crea rama de feature
git checkout -b feature/mi-mejora

# 3. Commit de cambios
git commit -am 'Agregar mi mejora'

# 4. Push a rama
git push origin feature/mi-mejora

# 5. Pull request en GitHub
```

## Estándares de código

- JavaScript vanilla, sin frameworks innecesarios
- Comentarios en español
- Validación de entrada
- Manejo de errores robusto
- Testing recomendado
